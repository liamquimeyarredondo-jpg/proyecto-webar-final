Generar el archivo de reconocimiento de los dos afiches

Esta herramienta compila automáticamente las dos imágenes guardadas en el proyecto y descarga un único archivo poster.mind. La compilación se realiza en este navegador usando MindAR; las imágenes no se envían a un servicio externo.

Después de descargar

  1. Descargá el archivo poster.mind.
  2. En tu repositorio GitHub, abrí la carpeta targets.
  3. Subí ahí el archivo descargado, conservando exactamente el nombre poster.mind.
  4. Confirmá los cambios (Commit changes) y esperá que GitHub Pages actualice el sitio.
  5. Volvé a abrir el enlace principal desde el celular y probá ambos afiches.
